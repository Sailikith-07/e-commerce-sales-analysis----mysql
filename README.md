# 🛒 E-Commerce Sales Analysis Using SQL

## 📌 Project Overview

Hello, my name is **Sailikith**.  
In this project, I used **SQL** to analyze data from an e-commerce database called `Ecommerce_Sales`.  
The goal was to extract insights about sales trends, top-selling products, customer behavior, and payment patterns.

This project helped me apply real-world SQL concepts like **JOINS**, **GROUP BY**, **aggregate functions**, **subqueries**, **views**, and **stored procedures**.

---

## 🗂️ Database Structure

The database contains four main tables:

- **Customers**: customer_id, name, email, city  
- **Products**: product_id, name, category, price  
- **Orders**: order_id, customer_id, order_date, payment_method  
- **Order_Details**: order_detail_id, order_id, product_id, quantity

---

## 🔍 Key Objectives

- Identify top-performing products
- Analyze customer behavior and order patterns
- Understand sales performance over time
- Use SQL queries to simulate real business questions

---

## ✅ Questions Solved

### 🟢 Basic (5 Queries)
- List all customers with their city and email
- Show all products with their category and price
- Find all orders made using 'Credit Card'
- Get products priced above ₹100
- Display orders placed after a certain date

### 🟡 Intermediate (5 Queries)
- Total sales per product
- Orders count per customer
- Top 3 products by sales
- Average order value by payment method
- Orders with customer and product details

### 🔴 Advanced (4 Queries)
- Highest spending customer
- Products never ordered
- Create a view for order total
- Stored procedure: get monthly sales by input month

---

## 📊 Insights Gained

- Most frequently purchased products
- Highest revenue-generating items
- Preferred payment modes
- Cities with most active customers
